# 投稿模板 · 人间底稿

把这份文件复制一份，填好后连同正文一起发到投稿邮箱。
只有开头两行 `---` 之间的部分需要按格式填写，其余按正常文章写。

- 字数不限，但故事主体要完整：有起头、有推进、有落点，能独立成篇。
- 标题不超过 20 字，摘要一句话（会出现在头版和归档列表）。
- `series` 留空即独立短篇；要归入现有系列，填系列标识（如 `office-story`）。
- `author` 写署名，真名或笔名均可；`authorurl` 是可选个人主页，没有就整行删掉。
- `publishedAt` 由编辑在刊登时填写，投稿时保留原样即可。
- `cover` 图片内容没有就将 cover 相关内容删掉
- `cover.src` 图片链接给出对应图片即可，如果不想使用国内AI生成，可提前告知，可按照需求帮忙生成头图。
- `cover.caption` 图片描述或者短文图片插图描述，可以简单叙述，也可以写为《某某文章》插图

```
为小说《[文章标题]》绘制一幅横向 3:2 的报纸插画。画面以[故事中的人物、动作或关键物件]为主体，背景是[故事发生的具体场所与时间]。通过人物姿态、空间距离和环境细节表现[故事的情绪或冲突]，不要直接画出结局。采用传统木刻版画风格，以深色油墨和浅色纸张为主，用细密排线刻画光影与材质。构图清晰，保留适当留白，使画面缩小后仍能辨认主体。不要添加文字、标题、标志或边框。
```

## 小标题用两个井号

引用、对话、列表都可以正常使用：

> 一段引用。

写完请自查三件事：

1. 有没有出现真实公司、甲方、项目代号、客户姓名，需要替换或模糊处理。
2. 是否一稿多投：若同时在投其他平台，请在信里提前告知。
3. 署名、联系方式、是否需要匿名，是否写清楚了。
